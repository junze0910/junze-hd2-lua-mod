## 1. 能解锁什么（9 行开关）

| 开关 | 做法 |
|---|---|
| 解锁武器 **P-41 巡察者**（副武器） | 克隆同类样板 **P-2 和平制造者** |
| 解锁武器 **G-11 铁蒺藜**（投掷物） | 克隆同类样板 **G-6 破片弹** |
| 解锁战备 **轨道照明弹**（ID5） | ② ③ |
| 解锁战备 **FRV 补给型（M-103）**（ID26） | ② ③ |
| 解锁战备 **快速侦察载具 FRV（M-102）**（ID105） | ② ③ |
| 解锁战备 **FRV 炽热型（M-104）**（ID135） | ② ③ |
| 解锁战备 **飞鹰·空空导弹**（ID146，`(NOT USED)` 废弃条目） | ② ③ |

> ② = `StratagemInfo +0x80 bit1 = 1`（= 明文数据的 `selectable`）
> ③ = 注册表记录 `+0x14 = 2`（∈{2,4} 即"可用/已登记"）

## 2. 两个配方

**武器 = 克隆同类样板 + 只替换身份字段**
把样板的 184B 注册表记录与 24B 映射**原样复制**到追加位，只改 `+0x00`（下标）/`+0x04`/`+0x08` 三个身份字段，其余**逐字节照抄**；`count` 最后发布。关掉开关 = 清空追加位 + `count` 回退。

**战备 = ② 选择位 + ③ 记录状态**
`StratagemInfo +0x80 bit1` 置 1，注册表记录 `+0x14 = 2`。关掉开关按打开前记录的原值还原。

写入前一律：**预检页可写 → 写 → 回读校验**（失败即回滚/记日志），只写自己算出来的那几个字节。

## 3. 安装

1. 装 **Bingus Shared Loader v15+**（MODS 页需要它提供 `ModOptionsMenu`）
2. 用 mod 管理器导入 `Unlock-Kit-v0.7.zip` 并启用
3. **进一次任务**（注册表/升级树在进任务后才加载；日志会先打印"等注册表就绪"）
4. ESC → MODS → 分组 **`A HD2 MOD COLLECTION`** → 找带 `[解锁台]` 前缀的那些开关 → 打开你要的

---

## 4. 配置与生效时机

| 时机 | 行为 |
|---|---|
| 打开开关 | 立刻写（武器=追加一条；战备=选择位+记录） |
| 关掉开关 | 按打开前的原值**精确回滚** |
| 每次启动游戏 | 注册表**每局重建**：MOM 里还开着的开关会**自动套用**一遍 |
| 每 5 秒 | 复核（武器条目是否还在 / 战备选择位与记录），被改回就补回 |
| 进任务后再开 | 可以，但战备列表在进任务时构建 → 一般**下一局**才在列表里看到 |

## 5. 排障

日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\UnlockKit.log`

| 现象 | 先看什么 |
|---|---|
| MODS 页里没有 `A HD2 MOD COLLECTION` 分组 | 确认 Loader 已启用；`Logs\MDL-Boot.log` 里应有 `mods/dsh/unlock_kit` |
| 开关打开但没生效 | 日志里若在刷 `等注册表就绪（门闸=…）` = 表还没加载 → **进一次任务** |
| 武器解锁被拒 | 日志 `追加位 #N 不是空的 → 拒绝` = 该位置被占用（同局重复追加/别的 mod 也在追加）→ 关掉重开或重启 |
| 战备解锁后列表里没有 | 确认有 `★ …：选择位 +0x80 … → 0x03` 与 `记录#… +0x14 … → 2`；战备列表下一局才重建 |
| 日志出现 `开关异常` | 把日志尾部发我 |

## 6. 已知限制

- **只做指定条目**（源码里的白名单），**没有"全部解锁"**；要加条目得改源码
- 会话级内存写入：重启游戏回到原装（MOM 的开关会被记住 → 下次开局自动重写）
- **不含武器配件解锁**：曾尝试 JAR-5 弹药（v0.1f~v0.5）；v0.5 写入虽全部成功，但**打开主宰（JAR-5）配装页会让游戏崩溃**，用户决定停线，v0.6 起整块移除。完整经过/实机真值/教训：`hd2-mod/docs/UNLOCK-KIT-交接.md §10`
- 离线夹具：`python _probe\test_unlock_kit.py` → **32/32**
- 支持构建：`helldivers2.exe` 1.8.46015.0（Steam build 25480438）；换版本可能失效（此时**拒绝写入**并记日志）
