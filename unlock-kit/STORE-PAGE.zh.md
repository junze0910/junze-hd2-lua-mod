# 解锁台（Unlock Kit）

**项目地址 / 下载：** https://github.com/junze0910/junze-hd2-lua-mod/releases/latest
**当前版本：** v0.6

## Description · 简介

把「解锁某件东西」变成游戏 **原生 ESC → MODS 页**里的**一行一个 是/否 开关**——**打开就写、关掉就还原**。

- **武器 2 把**：P-41 巡察者（副武器）、G-11 铁蒺藜（投掷物）——做法是**克隆同类样板，只替换身份字段**
- **战备 6 条**：轨道照明弹 / FRV 补给型（M-103）/ 快速侦察载具 FRV（M-102）/ FRV 炽热型（M-104）/ 飞鹰·空空导弹（废弃条目）/ 风暴漩涡
- **只读侦察**一行：打印目标 key、是否已登记、样板下标、战备记录与选择位
- 全部改动发生在**运行时内存**，不修改任何游戏文件；禁用 mod 后重启游戏即完全还原

> ✅ **v0.6 已实机验证通过（用户确认，2026-10-04）**：武器 2 把 / 战备 6 条 / 只读侦察均正常。
> ⚠️ **只做指定条目，不做"全解锁"**；**不含武器配件解锁**（v0.6 已移除，原因见下）。

## Main features · 主要特性

### 1. 一行一个开关

在游戏原生 **ESC → MODS 页 → 「解锁台」** 下，每个目标一行；**打开即写、关掉即按行精确回滚**。

### 2. 武器解锁 = 克隆同类样板 + 只换身份字段

把同类样板（P-41 ← P-2、G-11 ← G-6）的 184B 注册表记录与 24B 映射**逐字节复制**到追加位，
只改 `+0x00/+0x04/+0x08` 三个身份字段，`count` 最后发布。实机已验证：两把武器正常进军械库。

### 3. 战备解锁 = ② 选择位 + ③ 记录状态

- ② `StratagemInfo +0x80 bit1` 置 1（= 明文数据 `selectable`）
- ③ 注册表记录 `+0x14 = 2`（∈{2,4} 即"可用/已登记"）

实机已验证 6 条战备（ID5/26/105/135/146/50）。

### 4. 开局自动套用（注册表每局重建）

注册表在每局重建、内存写入是会话级 → 每次启动游戏，mod 会把 MOM 里仍开着的开关**自动重写**一遍。

### 5. 每 5 秒复核

复核"武器条目还在不在 / 战备选择位与记录有没有被改回"，被改回就立刻补回。

### 6. 会话级、可还原

写入只在本次游戏进程内有效；重启游戏即回到原装。想立刻还原：把对应开关**关掉**即可。

### 7. 只读侦察

`● 侦察（只读）` 打开时打印一次现状（不写任何字节），用于排障。

## Operation flow · 操作流程

1. **装前置**：Bingus Shared Loader **v15+**（MODS 页来自它提供的 `ModOptionsMenu`）
2. **装本 mod**：`Unlock-Kit-v0.6.zip`
3. **进一次任务**（注册表/升级树只在进任务后加载）
4. **配置**：ESC → MODS → 「解锁台」→ 打开需要的开关
5. **生效**：打开即写；战备列表在进任务时构建，改完一般**下一局**在列表里看到

## Compatibility · 兼容性

- 只写**指定条目**的注册表记录/映射 + 对应 `StratagemInfo` 选择位；不碰其它表
- 与其它 mod 共存；但**改同一条战备记录的 mod（例如 Strat-Unlock）算改同一块内存** —— 同时装时两边开关会互相影响，建议二选一
- 不新增槽位、不改槽位数量；**不含配件解锁**

## Known limits · 已知限制

- **没有"全部解锁"**：目标表是源码里的显式白名单
- 战备列表在进任务时构建 → 改完一般下一局才看到
- **武器配件（JAR-5 弹药）解锁已移除**：v0.5 写入全部成功但**打开主宰配装页会崩溃**（用户决定停线）
- 游戏版本变化可能导致定位失败 —— 此时 mod **拒绝写入并记日志**，不会乱写
