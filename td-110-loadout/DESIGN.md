# TD-110 挂载切换（tank_storm_loadout）· 设计定稿

> 状态：**源码完成 + 离线回归 85/85 通过**（2026-10-02）· 实机待验
> 取代：`td-110-co-op`（TD-110 Co-Op）+ `td-110-driver-armament`（Busier TD-110 Driver）
>   —— 两个旧包改的是**同一条记录的同一个槽位**，本来就"二选一"；合并成一个包 + 模式切换。

## 一、四档模式

| 模式 | 驾驶员位 +48 | 炮手位 +24 |
|---|---|---|
| 原装 vanilla | 烟雾弹发射器 | 激光制导部件 |
| 合作 coop | 激光制导部件 | **烟雾弹发射器 ⇄ 40mm 机炮武器站** |
| 忙碌 busy | **重机枪武器站（主）⇄ 40mm 机炮武器站** | 激光制导部件 |
| 自定义 custom | 5 选 1 | 5 选 1 |

* **硬不变量：两个槽位恰好一个激光**。三个预设的任何子选项组合都自检；
  **自定义同样受限**（想放第二个激光会被拒，并把控件弹回当前值 + 日志说清）。
* **射界 360° 是独立开关、默认开、与模式无关**：激光炮塔 + 加特林主炮的**水平**射界都改成 ±180。
  关掉就写回原装 ±20。射界是引擎实时读 → **立刻生效**，不用重新召唤。
* ⚠ **只解水平射界（`+28` 下限 / `+32` 上限），不解除视角限制** —— 操作炮塔时的视角范围原样保留。

## 三、两条腿（都以 HD2 Scanner 为前置）

| 要改的 | 表 | 定位 | 复核 |
|---|---|---|---|
| 两个槽位的 item | `MountComponentData` `0x3845B1E0` | 索引区本体哈希 `B0C9FAF4AF8903F9` → recIdx（实测 123）→ 记录区起点**运行时推**（实测 +5184 = 324×16） | 按**已知槽位下标**取 node：槽0 `0xE30C5711` / 槽1 `0xB7E9B43D` / 槽2 `0x79CC4582`。⚠ 槽1 的 node 被 TD-220 共用，**不能当身份** |
| 射界 | `TurretComponentData` `0x1EBA7593` | 索引区武器哈希：激光 `C36B5B37C058DBDD`（实测 recIdx 28）、加特林 `D58AE6A04EDB10DE`（实测 recIdx 29）；记录 `+28` 下限 / `+32` 上限（float） | 读到的射界必须是已知形态（±20 或 ±180），否则拒写 |

**真起点 = 最大的合法候选**（+5184 / +2336）。实测更小的候选（+4944 / +4704）也能"找到本体哈希"，
但落到的记录槽位全 0 / node 是别的车 —— 靠槽位 node 复核筛掉（离线夹具里专门埋了这个诱饵）。

## 四、配置界面与 cfg

**配置走 ModOptionsMenu（原生 MODS 页）**，7 个控件：
模式 / 合作·炮手武器 / 忙碌·驾驶员武器 / 自定义·驾驶员挂载 / 自定义·炮手挂载 / 射界 360° / 初始化。
Scanner 面板那一页只放**只读状态 + 现实值 + 诊断 + 两个动作**。

`%LOCALAPPDATA%\CowboyBingus\Helldivers2\TankStormLoadout.cfg`（1 秒热重读）：

```
mode     = coop          # vanilla | coop | busy | custom
coop_gun = smoke         # smoke(烟雾弹) | autocannon(40mm)
busy_gun = hmg           # hmg(重机枪·主) | autocannon(40mm)
yaw360   = 1
driver   = C36B5B37C058DBDD   # 仅 custom；白名单外直接忽略
gunner   = 3A061009AA31E9CB
```

## 五、时序（实机踩过）

* `MountComponentData` 是**生成载具时读一次** → 换完挂载要**重新召唤**坦克；
  进任务后等日志出现 `已写：驾驶员位(+48) …` / STATUS 里的 `OK` 再召唤。
* `TurretComponentData` 射界是**实时读** → 改完立刻生效。
* 消费者用 `declare_need()` 让 Scanner 当帧同步刷一次（§7.2），不必干等 30 秒。

## 六、红线

* 只写目标字段（两个槽位的 8 字节 item / 射界 8 字节），node 与 flags **一字不动**
* 槽位里的值不在白名单（= 别的 mod 改过）→ **拒写**，不覆盖别人
* 写前 VirtualProtect、写后回读校验；失败一律记 refuse，绝不当成功
* 不碰 `WeaponMagazineComponentData`（弹匣腿已按用户决定去掉）
