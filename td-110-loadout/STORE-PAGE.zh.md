# TD-110 挂载切换（TD-110 Loadout）

**项目地址 / 下载：** https://github.com/junze0910/junze-hd2-lua-mod/releases/latest
**当前版本：** v1.0.1

## Description · 简介

把《绝地潜兵 2》的**风暴漩涡坦克（TD-110，`tank_storm`）**变成可配置：

- 驾驶员位（记录 `+48`）装什么
- 炮手位（记录 `+24`）装什么
- 激光炮塔 / 加特林主炮的**水平射界**要不要放到 360°

它取代旧版 `TD-110 Co-Op`（更强调合作）与 `Busier TD-110 Driver`（更忙的驾驶员）的二选一方案：
旧版两者改的是**同一条记录的同一个槽位**，同时装会互相覆盖。本 mod 把它们合并成一个包 + 模式切换，
所有改动都发生在运行时内存，不修改任何游戏文件，禁用后重启游戏即完全还原。

## Main features · 主要特性

### 1. 四档模式

| 模式 | 驾驶员位（`+48`） | 炮手位（`+24`） |
|---|---|---|
| **原装** | 烟雾弹发射器 | 激光制导部件 |
| **合作** | 激光制导部件 | **烟雾弹发射器 ⇄ 40mm 机炮武器站** |
| **忙碌** | **重机枪武器站 ⇄ 40mm 机炮武器站** | 激光制导部件 |
| **自定义** | 5 选 1 | 5 选 1 |

> 「忙碌」的驾驶员位默认是**重机枪武器站**，可切成 40mm 机炮武器站。

### 2. 可选挂载（5 件）

| 挂载 | 说明 |
|---|---|
| **重机枪武器站** | 实弹武器站，射界本来就 ±180 |
| **40mm 机炮武器站** | 正规挂载项，射界本来就 ±180 |
| **额外导弹发射器** | 就是 TD-110 原装的发射井（原在槽 3/4） |
| **烟雾弹发射器** | TD-110 原装件（驾驶员位） |
| **激光制导部件** | TD-110 原装件（炮手位），射界原装 ±20° |

### 3. 硬规则：两个槽位恰好一个是激光

- **必须有一个**激光
- **不能两个都是**激光（会互相抢引导）
- 违反规则的改动会被**拒绝**并写明原因 —— 自定义模式也一样，控件会自动弹回当前值

### 4. 射界 360°（独立开关、默认开）

- 把**激光炮塔**与**加特林主炮**的水平射界从 ±20° 放宽到 **±180°（360°）**
- **与模式无关**：原装 / 合作 / 忙碌 / 自定义都生效
- ⚠ **只解水平射界，不解除视角限制**（炮塔转得满，看得未必满）
- 关掉开关会写回原装 ±20°；射界是引擎实时读的，改完**立刻生效**

### 5. 随便改

- 模式与子选项可以**反复来回切换**，改完再改照样生效
- 写入判据是「本 mod 可能写过的任何一件挂载」，不是只认原装 —— 不会出现"一个槽只能改一次"

### 6. 初始化

- 一键全部还原为原装：驾驶员＝烟雾弹发射器、炮手＝激光制导部件、射界 ±20°
- 即使槽位被别的 mod 改成了**认不出来的值**，也能**强制写回**
- cfg 同时复位（模式回原装、射界开关回关）

## Operation flow · 操作流程

### 第一步：安装前置

1. 安装 **Bingus Shared Loader v15+（API 1）**，或兼容的 MDL；
2. 安装 **Mod Options Menu v1.1+**（提供原生 MODS 设置页）；
3. 安装 **HD2 Scanner v0.7.0+**（提供挂载表 / 射界表地址）；
4. 用 HD2 管理器导入 `TD-110-Loadout-v1.0.1.zip`，启用并部署；
5. 启动游戏。

### 第二步：进入设置页

1. 在游戏里按 **ESC** 打开菜单；
2. 切到 **MODS** 页；
3. 选择 **TD-110 挂载切换**。

### 第三步：选择配置

1. **模式**：原装 / 合作 / 忙碌 / 自定义；
2. 选了 **合作** → 再选「**合作·炮手武器**」：烟雾弹发射器 / 40mm 机炮武器站；
3. 选了 **忙碌** → 再选「**忙碌·驾驶员武器**」：重机枪武器站 / 40mm 机炮武器站；
4. 选了 **自定义** → 分别选「**自定义·驾驶员挂载**」与「**自定义·炮手挂载**」（各 5 选 1）；
5. **射界 360°**：默认已开，不需要可以关掉；
6. 改完**立即写入**（不像其它 mod 需要按 Apply）。

也可以不进游戏改：编辑
`%LOCALAPPDATA%\CowboyBingus\Helldivers2\TankStormLoadout.cfg`（**1 秒热重读**）。

### 第四步：进任务，先别召唤坦克

⚠ **这是本 mod 最容易踩的坑**：挂载表（`MountComponentData`）是**生成载具时读一次**的静态配置，
补丁必须**早于召唤载具**。

1. 进入任务后，**先不要召唤坦克**；
2. 等日志出现挂载写入的那两行：

```text
[TankStormLoadout] 已接上 HD2Scanner（前置）：挂载表 + 射界表由 Scanner 提供
[TankStormLoadout] 已写：驾驶员位(+48) CBE931AA0910063A -> 3A061009AA31E9CB（recIdx 123，node/flags 未动）
[TankStormLoadout] 已写：炮手位(+24)   DDDB58C0375B6BC3 -> CBE931AA0910063A（recIdx 123，node/flags 未动）
```

3. 看到之后**再召唤坦克**。

> 射界（`TurretComponentData`）是引擎**实时读**的，写进去就生效 —— 不需要等，也不需要重新召唤。

### 第五步：召唤坦克确认

召唤出来的坦克就是当前配置。状态盘可以随时核对：

```text
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\TankStormLoadout_STATUS.log
```

第一行出现 `OK - 补丁生效中（挂载 N 处 / 射界 N 处）` 就表示生效了。

### 第六步：后续修改

每次改配置后：

1. 在 MODS 页改选择（或改 cfg）；
2. 等日志出现新的 `已写：…` 两行；
3. **重新召唤一辆坦克**（已经开出来的那台不会跟着变）；
4. 射界不需要重新召唤 —— 改完立刻生效。

### 第七步：初始化

要回到原始默认：

1. 在 TD-110 页面找到「**初始化（全部还原为原装 + cfg 复位）**」；
2. 打开并应用；
3. 会执行：
   - 驾驶员位写回**烟雾弹发射器**
   - 炮手位写回**激光制导部件**
   - 激光炮塔 / 加特林主炮射界写回 **±20°**
   - CFG 回到默认（模式＝原装、射界开关＝关）
   - 清空写入状态
4. 日志会写：

```text
[TankStormLoadout] 初始化：全部还原为原装（驾驶员=烟雾弹 / 炮手=激光 / 射界 ±20），cfg 也复位
```

## Requirements · 依赖

* **Helldivers 2**（测试于 `1.8.45850.0`）
* **Bingus Shared Loader v15+（API 1）**，或兼容的 MDL
* **Mod Options Menu v1.1+** —— 设置 UI 前置
* **HD2 Scanner v0.7.0+** —— 挂载表 / 射界表地址的前置
* 一个能导入 zip 的 HD2 mod 管理器（HD2MM / Arsenal 等）
* Windows x64

> 必需前置：**HD2 Scanner**。缺少它时本 mod **零写入**，只把原因写进日志与状态行（不会乱写内存）。
> 缺少 ModOptionsMenu 时改不了设置页，但仍可手改 cfg（1 秒热重读）。

## Compatibility · 兼容性

* 取代 `TD-110-Co-Op` 与 `TD-110-Busier-Driver`（两者**已废弃、不再分发**）；
  建议不要与旧版同时启用，避免重复写入。
* 只改本机内存；联机时其他玩家通常看不到你的改动。
* 与其它改 TD-110 的 mod 同时使用时，若槽位出现本 mod 不认识的值，会**拒写**（不覆盖别人的改动）；
  想强行带回原装请用「**初始化**」。
* 游戏启用 nProtect GameGuard，使用第三方工具的风险由使用者自行承担。

## Known limits · 已知限制

* 挂载是「**生成载具时读一次**」：改完必须**重新召唤**坦克；已经开出来的那台不会跟着变。
  射界是实时读的，不受此限。
* 「忙碌」档的**重机枪武器站**在游戏数据里**不是一个挂载项**（它是独立的武器实体），
  弹药走它自己的默认配置 —— 旧版曾为它打过「弹匣 1000 发」的补丁，**本版已按要求去掉**；
  如果你更在意持续火力，建议用 **40mm 机炮武器站**那一档。
* **只解水平射界**：视角范围原样保留，所以炮塔转得满、看得未必满。
* 设置页用 ModOptionsMenu，只支持开关 / 固定选项，**不支持自由文本输入**。
* 首次加载后没有热重载；更新 mod 版本需要重启游戏。
