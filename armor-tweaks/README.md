# 装甲车辆轻度改装（Armor Tweaks）· 使用说明

**版本：v1.0.0** ｜ 前置：**Bingus Shared Loader v15+** + **HD2 Scanner v0.8.2+**（必需）+ **Mod Options Menu v1.1+**

> 🆕 **v1.0.0 由原「TD-110 挂载切换」扩写而来** —— TD-110 那部分行为不变，新增 **TD-220 堡垒 MK XVI** 与 **40mm 机炮弹种**。
> ⚠ **模块 id 与 GUID 都换了** ⇒ 在 mod 管理器里是**另一个条目**，旧的 `TD-110 Loadout` 请手动删掉再装这个。

> 一句话：**把装甲载具的挂载 / 射界 / 弹种做成管理页里的一行一选项。**

---

## 1. 能力总览

| MOM 行 | 类型 | 作用 |
|---|---|---|
| `[TD-110] 预设` | choice × 6 | 原装 / 合作·烟雾 / 合作·40mm / 忙碌·重机枪 / 忙碌·40mm / 自定义 |
| `[TD-110] 炮手槽位` | choice × 5 | 直接选槽里的物品（改完自动切「自定义」） |
| `[TD-110] 驾驶员槽位` | choice × 5 | 同上 |
| `[TD-220] 重机枪位` | choice × 2 | **原装「堡垒同轴重机枪」⇄「40mm 机炮武器站」** |
| `[40mm] 弹种` | choice × 2 | **40mm 穿甲高爆 ⇄ 20mm 高射（近炸子母）** |

**默认开启、不占行**：TD-110（激光炮塔 + 加特林主炮）与 **TD-220（主炮 + 同轴重机枪）** 四条炮塔的**水平射界全部解锁到 ±180**。

「初始化」在 Scanner 的全局按钮里（`A HD2 MOD COLLECTION` 分组第 4 行），会把上面**全部**还原成原装。

## 2. 生效时机

| 改什么 | 什么时候生效 |
|---|---|
| TD-110 / TD-220 的**挂载槽位** | **重新召唤**载具 |
| 四条**炮塔射界** | **实时**（引擎每次读表） |
| **40mm 弹种** | **实时** |
| 在飞船里改 | 进任务后生效 |

## 3. 三个「别踩」

1. **node 不能当身份**：`0xB7E9B43D` 被 TD-110 炮手位和 TD-220 同轴机枪位**共用**（同底盘）。本 mod 一律用 `MountComponentData` 索引区的**本体哈希**定位记录，node 只做二级复核。
2. **设备 id 会随构建漂移**，所以全部**运行时读**索引区，不硬编码 recIdx。
3. **认不出来的当前值一律拒写**（别的 mod 动过？），只在日志里说清原因；想强行写回原装点「初始化」。

## 4. 前置

- **HD2 Scanner v0.8.2+** —— 本 mod 找表全靠它（挂载表 / 炮塔表 / **弹道表**）。v0.8.2 才广播 `ProjectileWeaponComponentData`，所以 40mm 弹种切换需要它。
- **Mod Options Menu v1.1+** —— 管理页本体。

## 5. 排障

日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ArmorTweaks.log`

| 现象 | 先看什么 |
|---|---|
| MODS 页里没有 `A HD2 MOD COLLECTION` | `Logs\MDL-Boot.log` 应有 `mods/dsh/armor_tweaks: loaded` |
| 改了挂载没变化 | 挂载是「生成载具时读一次」→ **重新召唤**；日志里应有 `已写：TD-110 驾驶员位…` |
| TD-220 那格写了没反应 | 确认你开的是 **TD-220 堡垒**（不是暴风漩涡坦克）；日志里应有 `TD-220 重机枪位(+24)` |
| 弹种切了没变化 | 日志里应有 `已写弹种：40mm 机炮 40mm 穿甲（原装） -> 20mm 高射` |
| 一直拒写 | 日志会写明原因（当前值不是认识的形态 / 表还没就绪 → 进一次任务） |
