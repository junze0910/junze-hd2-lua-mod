# 装甲车辆轻度改装（Armor Tweaks）· 使用说明

**版本：v1.1.0** ｜ 前置：**Bingus Shared Loader v15+** + **HD2 Scanner v0.8.2+**（必需）+ **Mod Options Menu v1.1+**

> 一句话：**把装甲载具的挂载 / 射界 / 弹种做成管理页里一行一选项** —— 覆盖 **TD-110 风暴漩涡坦克**、**TD-220 堡垒 MK XVI**、**M-102 快速侦查载具**。

> 🆕 **v1.1.0**：新增 **`[M-102] 车载武器`**（原装车载重机枪 ⇄ 重机枪武器站 ⇄ 40mm 机炮武器站，**两个变体一起写**）；
> 挂载腿改为**按车独立**（一辆车认不出来不再牵连其它车）。TD-110 / TD-220 / 40mm 弹种 / 射界行为**不变**。
> ⚠ **模块 id 与 GUID 与 v1.0.0 相同** ⇒ 管理器里是**同一个条目**，可直接换包。

---

## 1. 能力总览（MODS 页 6 行）

| MOM 行 | 类型 | 作用 |
|---|---|---|
| `[TD-110] 预设` | choice × 6 | 原装 / 合作·烟雾 / 合作·40mm / 忙碌·重机枪 / 忙碌·40mm / 自定义 |
| `[TD-110] 炮手槽位` | choice × 5 | 直接选槽里的物品（改完自动切「自定义」） |
| `[TD-110] 驾驶员槽位` | choice × 5 | 同上 |
| `[TD-220] 重机枪位` | choice × 2 | **原装「堡垒同轴重机枪」⇄「40mm 机炮武器站」** |
| `[40mm] 弹种` | choice × 2 | **40mm 穿甲高爆 ⇄ 20mm 高射（近炸子母）** |
| `[M-102] 车载武器` | choice × 3 | **原装车载重机枪 ⇄ 重机枪武器站 ⇄ 40mm 机炮武器站** |

**默认开启、不占行**：TD-110（激光炮塔 + 加特林主炮）与 **TD-220（主炮 + 同轴重机枪）** 四条炮塔的**水平射界全部解锁到 ±180**。

> ⚠ M-102 **没有射界腿**：它的车载武器在游戏数据里**没有 `TurretComponentData` 记录**

**「初始化」**在 Scanner 的全局按钮里（`A HD2 MOD COLLECTION` 分组），会把上面**全部**还原成原装
（TD-110 驾驶员=烟雾弹 / 炮手=激光；TD-220 重机枪位=原装同轴重机枪；**M-102=原装车载重机枪**；40mm=穿甲；四条炮塔射界写回 ±20），cfg 也一并复位。

### 1.1 按车独立（v1.1.0 起）

挂载腿**逐辆车独立定位 / 独立复核 / 独立写入**：哪辆车的记录缺失、node 对不上，**只跳过那辆车**，
其它车照常生效；日志会写明：

```text
[ArmorTweaks] 挂载表 0x…：以下车辆本轮跳过（按车独立，不影响其它车）—— TD-220：记录没找到
```

（v1.0.0 的判据是「四条记录全部找到且全部复核通过才写」—— 任何一个变体改名/换模型，TD-110 也会跟着停写。）

### 1.2 M-102 同时覆盖两个变体

`[M-102] 车载武器` 一次写**两个变体**：`M-102 快速侦查载具` 与 `M-102 快速侦查载具（地图产出）`
（两条挂载记录逐字段相同；其中一条复核不过时，另一条照写）。

## 2. 安装

1. 装 **Bingus Shared Loader v15+（API 1）**（或兼容的 MDL）；
2. 装 **Mod Options Menu v1.1+**（原生 MODS 设置页）；
3. 装 **HD2 Scanner v0.8.2+**（提供挂载表 / 炮塔表 / 弹道表地址）；**这是硬前置 —— 缺了本 mod 零写入**；
4. 用 HD2 mod 管理器导入 `Armor-Tweaks-v1.1.0.zip`，启用并 Deploy；
5. 启动游戏（数据表是在**任务里**按需加载的，进图后约 1 分钟才就绪）。

---

## 3. 配置（游戏内 ESC → MODS 页）

分组 `A HD2 MOD COLLECTION` 下的 6 行，改完立即写入，**不需要按 Apply**：

| 想做什么 | 怎么点 |
|---|---|
| TD-110 整体换一套 | `[TD-110] 预设`（6 档） |
| TD-110 单独换某个槽 | `[TD-110] 炮手槽位` / `[TD-110] 驾驶员槽位`（改完自动切「自定义」） |
| TD-220 换同轴机枪 | `[TD-220] 重机枪位` |
| 40mm 换弹种 | `[40mm] 弹种` |
| **M-102 换车载武器** | **`[M-102] 车载武器`**（三选一） |
| 全部还原 | Scanner 分组的**全局「初始化」**按钮 |

也可以**不进游戏改**：编辑 cfg（**1 秒热重读**）：

`%LOCALAPPDATA%\CowboyBingus\Helldivers2\ArmorTweaks.cfg`

```ini
mode     = coop          # vanilla | coop | busy | custom
coop_gun = smoke         # smoke(烟雾弹) | autocannon(40mm)
busy_gun = hmg           # hmg(重机枪) | autocannon(40mm)
yaw360   = 1             # 0 才写回原装 ±20（默认 1 = 四条炮塔 ±180）
driver   = C36B5B37C058DBDD   # 仅 custom；白名单外直接忽略
gunner   = 3A061009AA31E9CB
td220    = hmg           # hmg(原装同轴重机枪) | ac40(40mm 机炮武器站)
proj     = ap            # ap(40mm 穿甲) | aa(20mm 高射)
m102     = frv           # frv(原装车载重机枪) | hmg(重机枪武器站) | ac40(40mm 机炮武器站)
```

## 4. 生效时机

| 改什么 | 什么时候生效 |
|---|---|
| TD-110 / TD-220 / **M-102** 的**挂载槽位** | **重新召唤**该载具 |
| 四条**炮塔射界**（TD-110 ×2 + TD-220 ×2） | **实时**（引擎每次读表） |
| **40mm 弹种** | **实时** |
| 在飞船里改 | 进任务后生效 |

> ⚠ 挂载表（`MountComponentData`）是**生成载具时读一次**的静态配置 —— 补丁必须早于召唤。
> 进任务后先等日志出现写入行（`已写：…` / `已写：M-102 车载武器位(slot0) …`）**再召唤载具**。

## 5. 排障

日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ArmorTweaks.log`（状态盘 `…_STATUS.log`）

| 现象 | 先看什么 |
|---|---|
| MODS 页里没有 `A HD2 MOD COLLECTION` | `Logs\MDL-Boot.log` 应有 `mods/dsh/armor_tweaks: loaded` |
| 改了挂载没变化 | 挂载是「生成载具时读一次」→ **重新召唤**；日志里应有 `已写：TD-110 驾驶员位…` |
| TD-220 那格写了没反应 | 确认你开的是 **TD-220 堡垒**（不是暴风漩涡坦克）；日志里应有 `TD-220 重机枪位(+24)` |
| **M-102 那格写了没反应** | 确认你开的是 **M-102 快速侦查载具**；日志里应有 `已写：M-102 车载武器位(slot0) …`（两个变体各一行） |
| 只有一辆车生效了 | 正常 —— **按车独立**：看日志的 `以下车辆本轮跳过`，会写明是哪辆车、为什么 |
| 弹种切了没变化 | 日志里应有 `已写弹种：40mm 机炮 40mm 穿甲（原装） -> 20mm 高射` |
| 一直拒写 | 日志会写明原因（当前值不是认识的形态 / 表还没就绪 → 进一次任务） |

## 6. 已知限制

* **挂载要重新召唤**：已经开出来的那台不会跟着变。射界与弹种**实时**生效，不受此限。
* **射界只解水平**（记录 +28/+32）：**视角限制原样保留**，炮塔转得满、不一定看得满。
* **M-102 没有射界腿**（无 `TurretComponentData` 记录），只改车载武器。
* **M-102 的重机枪武器站 / 40mm 机炮武器站挂点与原厂不同**（原厂 `frv_mg` 的 node 是 `0x53BEC437`；
  40mm 机炮在别的车上用的是 `0xE9DC426A`）—— **2026-10-05 实机已写入并读回校验通过**：
  `已写：M-102 车载武器位(slot0) = 40mm 机炮武器站 4EC28E03DB1E5C08 -> FD885F1AB3EE7298（recIdx 19）`，
  `recIdx 117`（地图产出）同样成功，本轮 `拒绝=0`。个别构建若异常，切回「原装车载重机枪」即可。
* **只改本机内存、不发网络包** ⇒ **联机时队友看不到你的改动**（队友也装了同一 mod 才会各改各的）。
  40mm 弹种更明显：`rpc_synced_fire_events = 0`，开火事件本就不广播。
* TD-110 两槽**恰好一个激光**（会互相抢引导）：违反的改动会被**拒绝**并把控件弹回当前值。
* 认不出来的当前值**一律拒写**（别的 mod 动过？）→ 想强行回原装请点「初始化」。
* 首次加载后没有热重载：更新 mod 版本需要重启游戏。

## 7. 给开发者

* 源码：`junze-hd2-lua-mod/armor-tweaks/armor_tweaks.lua`（`local VERSION` 是版本号单源）；
* 设计：`armor-tweaks/DESIGN.md`；交接：`hd2-mod/docs/ARMOR-TWEAKS-交接.md`；
* 离线回归（lupa，不需要游戏）：`cd _probe; python test_armor_tweaks.py` → **期望 147/147**；
* 打包：`python tools\build_mod.py armor_tweaks` → `build/Armor-Tweaks-v<版本>.zip`；
* 包体检：`python tools\check_packages.py`；
* 三条腿的实现要点：
  * 挂载 = `MountComponentData` `0x3845B1E0`，按**索引区本体哈希**定位 → 按**槽位下标**复核 node → 只写 item 的 8 字节；
  * 射界 = `TurretComponentData` `0x1EBA7593`，记录 `+28/+32`（f32 下限/上限），只写**水平**；
  * 弹种 = `ProjectileWeaponComponentData` `0x45171B68`，记录 `+0`（u32 `projectile_type`）。
* **记录区起点运行时推**（`layout_cands` 取最大合法候选）；**recIdx 不硬编码**（版本漂移会变）。
