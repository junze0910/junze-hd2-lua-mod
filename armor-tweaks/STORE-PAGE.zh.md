# 装甲车辆轻度改装（Armor Tweaks）

**项目地址 / 下载：** https://github.com/junze0910/junze-hd2-lua-mod/releases/latest
**当前版本：** v1.1.0

## Description · 简介

把《绝地潜兵 2》的**三辆装甲载具**变成可配置：

* **TD-110 风暴漩涡坦克**（`tank_storm`）—— 驾驶员位 / 炮手位各装什么、四种预设模式；
* **TD-220 堡垒 MK XVI** —— 同轴重机枪位要不要换成 40mm 机炮；
* **M-102 快速侦查载具**（含「地图产出」变体）—— 车载武器三选一；
* **四条炮塔**（TD-110 激光炮塔 + 加特林主炮、TD-220 主炮 + 同轴重机枪）的**水平射界**要不要放到 360°；
* **40mm 机炮的弹种**在 40mm 穿甲高爆 ⇄ 20mm 高射（近炸子母）之间切换。

它取代旧版 `TD-110 Co-Op` 与 `Busier TD-110 Driver`（两者改的是**同一条记录的同一个槽位**，本来只能二选一）。

> ✅ 所有改动都发生在**运行时内存**，不修改任何游戏文件；禁用 mod + 重启游戏即完全还原。

## Main features · 主要特性

### 1. MODS 页 6 行（原生设置页，分组 `A HD2 MOD COLLECTION`）

| 行 | 作用 |
|---|---|
| `[TD-110] 预设` | 原装 / 合作·烟雾 / 合作·40mm / 忙碌·重机枪 / 忙碌·40mm / 自定义 |
| `[TD-110] 炮手槽位` / `[TD-110] 驾驶员槽位` | 各 5 选 1（直接改 = 自动切「自定义」） |
| `[TD-220] 重机枪位` | 原装「堡垒同轴重机枪」⇄「40mm 机炮武器站」 |
| `[40mm] 弹种` | 40mm 穿甲高爆 ⇄ 20mm 高射（近炸子母） |
| **`[M-102] 车载武器`** | **原装车载重机枪 ⇄ 重机枪武器站 ⇄ 40mm 机炮武器站** |

### 2. 射界 360°（独立开关、默认开）

* 把 **TD-110 激光炮塔 + 加特林主炮**、**TD-220 主炮 + 同轴重机枪**的水平射界从 ±20° 放宽到 **±180°（360°）**；
* **与模式无关**（原装 / 合作 / 忙碌 / 自定义都生效）；关掉开关会写回原装 ±20°；
* 射界是引擎**实时读**的，改完**立刻生效**，不用重新召唤；
* ⚠ **只解水平射界，不解除视角限制**（炮塔转得满，看得未必满）。
* **M-102 没有射界腿** —— 它的车载武器在游戏数据里没有炮塔记录。

### 3. M-102 车载武器三选一（v1.1.0 新增）

* **原装车载重机枪**（`frv_mg`，默认）⇄ **重机枪武器站** ⇄ **40mm 机炮武器站**；
* 一次写**两个变体**：`M-102 快速侦查载具` 与 `M-102 快速侦查载具（地图产出）`；
* 挂载换完要**重新召唤 M-102** 才生效。

### 4. 按车独立（v1.1.0 起）

挂载腿**逐辆车独立定位 / 独立复核 / 独立写入**：哪辆车的记录缺失、挂点对不上，**只跳过那辆车**，
其它车照常生效（日志写明跳过了谁、为什么）。TD-110 不会再因为别的车改了数据而一起停写。

### 5. TD-110 硬规则：两个槽位恰好一个是激光

* **必须有一个**激光、**不能两个都是**（会互相抢引导）；
* 违反规则的改动会被**拒绝**并把控件弹回当前值 —— 自定义模式也一样。

### 6. 随便改 / 一键还原

* 模式与子选项可以**反复来回切换**，改完再改照样生效（判据是「本 mod 可能写过的任何一件挂载」，不是只认原装）；
* **初始化**（Scanner 分组的全局按钮）一键全部回原装：TD-110 驾驶员=烟雾弹 / 炮手=激光、TD-220 重机枪位=原装同轴重机枪、
  **M-102 = 原装车载重机枪**、40mm = 穿甲、四条炮塔射界 = ±20°、cfg 一并复位；
* **即使槽位被别的 mod 改成了认不出来的值，初始化也能强制写回**。

## Operation flow · 操作流程

### 第一步：安装前置

1. 安装 **Bingus Shared Loader v15+（API 1）**，或兼容的 MDL；
2. 安装 **Mod Options Menu v1.1+**（提供原生 MODS 设置页）；
3. 安装 **HD2 Scanner v0.8.2+**（提供挂载表 / 炮塔表 / 弹道表地址）—— **硬前置，缺了本 mod 零写入**；
4. 用 HD2 管理器导入 `Armor-Tweaks-v1.1.0.zip`，启用并部署；
5. 启动游戏。

### 第二步：进入设置页

1. 游戏里按 **ESC** 打开菜单；2. 切到 **MODS** 页；3. 找到分组 **`A HD2 MOD COLLECTION`**。

### 第三步：选择配置

1. TD-110：**预设**（6 档）或单独点**炮手槽位 / 驾驶员槽位**；
2. TD-220：**重机枪位**（原装同轴重机枪 / 40mm 机炮武器站）；
3. **M-102：车载武器**（原装车载重机枪 / 重机枪武器站 / 40mm 机炮武器站）；
4. 40mm：**弹种**（穿甲高爆 / 20mm 高射）；
5. 射界 360° **默认已开**，不需要可以关掉；
6. 改完**立即写入**，不需要按 Apply。

也可以不进游戏改：编辑 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\ArmorTweaks.cfg`（**1 秒热重读**）。

### 第四步：进任务，先别召唤载具

⚠ **这是本 mod 最容易踩的坑**：挂载表（`MountComponentData`）是**生成载具时读一次**的静态配置，补丁必须**早于召唤**。

1. 进入任务后**先不要召唤载具**；
2. 等日志出现写入行：

```text
[ArmorTweaks] 已接上 HD2Scanner（前置）：挂载表 + 射界表由 Scanner 提供
[ArmorTweaks] 已写：TD-110 驾驶员位(+48) … -> …（recIdx 123，node/flags 未动）
[ArmorTweaks] 已写：M-102 车载武器位(slot0) = 重机枪武器站 … -> …（recIdx 19，node/flags 未动）
```

3. 看到之后再召唤载具。

> 射界 / 40mm 弹种是引擎**实时读**的 —— 写进去就生效，不需要等、也不需要重新召唤。

### 第五步：确认生效

召唤出来的载具就是当前配置。状态盘可以随时核对：

```text
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ArmorTweaks_STATUS.log
```

第一行出现 `OK - 补丁生效中（挂载 N 处 / 射界 N 处）` 即表示生效。

### 第六步：后续修改 / 初始化

* 每次改配置后：等日志出现新的 `已写：…` → **重新召唤**那辆车（射界 / 弹种不需要）；
* 要回到原始默认：点 Scanner 分组的**全局「初始化」**按钮。

## Requirements · 依赖

* **Helldivers 2**（测试于 `1.8.45850.0`）
* **Bingus Shared Loader v15+（API 1）**，或兼容的 MDL
* **Mod Options Menu v1.1+** —— 设置 UI 前置
* **HD2 Scanner v0.8.2+** —— **必需**：挂载表 / 炮塔表 / 弹道表地址的前置
* 一个能导入 zip 的 HD2 mod 管理器（HD2MM / Arsenal 等）
* Windows x64

> 缺少 Scanner 时本 mod **零写入**，只把原因写进日志与状态行（不会乱写内存）。
> 缺少 ModOptionsMenu 时改不了设置页，但仍可手改 cfg（1 秒热重读）。

## Compatibility · 兼容性

* 取代 `TD-110-Co-Op` 与 `TD-110-Busier-Driver`（两者**已废弃、不再分发**）；建议不要与旧版同时启用。
* **v1.1.0 与 v1.0.0 的 GUID / 模块 id 相同** ⇒ 管理器里是同一个条目，可直接换包。
* 只改本机内存；**联机时其他玩家通常看不到你的改动**（本 mod 不发任何网络包）。
* **按车独立**：某辆车的表认不出来时只跳过那辆车，其它车照常。
* 与其它改同一辆车的 mod 同时使用时，若槽位出现本 mod 不认识的值，会**拒写**（不覆盖别人的改动）。
* 游戏启用 nProtect GameGuard，使用第三方工具的风险由使用者自行承担。

## Known limits · 已知限制

* 挂载是「**生成载具时读一次**」：改完必须**重新召唤**该载具；射界与弹种是实时读的，不受此限。
* **M-102 的重机枪武器站 / 40mm 机炮武器站**用的是与其它车相同的挂载项，但**挂点与原厂不同** ——
  **2026-10-05 实机已写入并读回校验通过**（`recIdx 19` 与 `117` 两个变体都成功，本轮 `拒绝=0`）；个别构建若异常，切回「原装车载重机枪」即可。
* **不提供 M-104 火焰喷射器**：该武器有资源加载问题（用户 2026-10-05 决定不用）。
* **只解水平射界**：视角范围原样保留，炮塔转得满、看得未必满。
* TD-110「忙碌」档的**重机枪武器站**在游戏数据里不是挂载项（是独立武器实体），弹药走它自己的默认配置；
  旧版曾为它打过「弹匣 1000 发」补丁，**本版已去掉**。
* 设置页用 ModOptionsMenu，只支持开关 / 固定选项，**不支持自由文本输入**。
* 首次加载后没有热重载；更新 mod 版本需要重启游戏。
