# 自定义补给（Custom Supply）v0.1e

**前置：** Bingus Shared Loader v15+ ｜ **Mod Options Menu v1.1+** ｜ **HD2 Scanner v0.8.0+（必需）**

## 简介

把补给包架的 **4 个槽位**交给你配置：**放什么，补给就投什么；放多少，冷却就多久。**

- 上层 4 槽可选：`无 / 弹药盒 / 针剂盒 / 手雷盒 / 补给包 / 医疗包 / 爆炸筒`
- 冷却按实际内容计算：**30 s（全空 / 爆炸筒）～ 150 s（四槽针剂盒 / 补给包 / 迷你核弹）**
- 游戏原生 **ESC → MODS 页** 内配置，下拉描述实时显示当前冷却
- 运行时内存改动，**不修改游戏文件**；禁用 mod 或重启游戏即完全还原

## SEAF 大炮覆盖

当场上**存在超级地球大炮 / SEAF Artillery** 时，可手动打开「SEAF 大炮覆盖」：

- 新增下层 4 个「大炮槽位」，与上层补给槽**独立配置**，互不同步
- 选 **补给类** → 沿用上层对应补给槽的物品
- 选 **炮弹 / 爆炸筒** → 使用下层选中的物品

下层可选：

| 选项 | 冷却增量 |
|---|---:|
| 补给类 | 沿用上层 |
| 大炮 迷你核弹 | +30 s |
| 大炮 高爆弹 | +20 s |
| 大炮 炸弹 | +15 s |
| 大炮 凝固汽油弹 | +10 s |
| 大炮 静电场 | +10 s |
| 大炮 烟雾弹 | +5 s |
| 爆炸筒 | +0 s |

炮弹摆位已自动套用，无需手动调。

## 安装

1. 先安装并启用 **Mod Options Menu v1.1+** 与 **HD2 Scanner v0.8.0+**
2. 用 mod 管理器导入 `Custom-Supply-v0.1e.zip` 并启用
3. 启动游戏，**进一次任务**（数据表在任务里加载）

## 使用

1. 游戏中按 **ESC → MODS 页 → 自定义补给**
2. 配置上层 4 个「补给槽位」
3. 若场上存在超级地球大炮 / SEAF Artillery：
   - 打开「**SEAF 大炮覆盖**」
   - 在下方 4 个「**大炮槽位**」中选择炮弹 / 爆炸筒
   - 想让某一槽继续用上层补给，就选「补给类」
4. 改完立即生效；若在任务中修改，下一局生效
