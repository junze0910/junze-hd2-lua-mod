# 自定义补给（Custom Supply）v0.1f

**前置：** Bingus Shared Loader v15+ ｜ **Mod Options Menu v1.1+** ｜ **HD2 Scanner v0.8.1+（必需）**

## 简介

把补给包架的 **4 个槽位**交给你配置：**放什么，补给就投什么；放多少，冷却就多久。**

- 上层 4 槽可选：`无 / 弹药盒 / 针剂盒 / 手雷盒 / 补给包 / 医疗包 / 爆炸筒`
- 游戏原生 **ESC → MODS 页 → 分组 `A HD2 MOD COLLECTION`** 内配置（本 mod 占 5 行，都带 `[补给]` 前缀），下拉描述实时显示当前冷却
- 游戏原生 **ESC → MODS 页** 内配置，下拉描述实时显示当前冷却
- 运行时内存改动，**不修改游戏文件**；禁用 mod 或重启游戏即完全还原

## 大炮覆盖模式

把 `[补给] 模式` 切到「**大炮覆盖**」后，**同样那 4 行「槽位」的下拉内容直接换成炮弹**：

- 4 行「槽位」= 大炮炮弹；选 **补给类** → 沿用**同一槽**在补给模式里的物品
- 选 **补给类** → 沿用上层对应补给槽的物品
- 选 **炮弹 / 爆炸筒** → 使用下层选中的物品

下层可选：

| 选项 | 冷却增量 |
|---|---:|
| 补给类 | 沿用上层 |
| 大炮 迷你核弹 | +30 s |
| 大炮 高爆弹 | +20 s |
| 大炮 炸弹 | +15 s |
| 大炮 凝固汽油弹 | +10 s |
| 大炮 静电场 | +10 s |
| 大炮 烟雾弹 | +5 s |
| 爆炸筒 | +0 s |

炮弹摆位已自动套用，无需手动调。

## 安装

1. 先安装并启用 **Mod Options Menu v1.1+** 与 **HD2 Scanner v0.8.1+**
2. 用 mod 管理器导入 `Custom-Supply-v0.1f.zip` 并启用
3. 启动游戏，**进一次任务**（数据表在任务里加载）

## 使用

1. 游戏中按 **ESC → MODS 页 → `A HD2 MOD COLLECTION`**
2. 配 `[补给] 槽位 1 ~ 4`（补给模式）
3. 若场上存在超级地球大炮 / SEAF Artillery：
   - 把 `[补给] 模式` 切到「**大炮覆盖**」；同样那 4 行的下拉会变成炮弹
   - 想让某一槽继续用上层补给，就选「补给类」
   - 切回「补给」模式即可恢复配置补给内容（两个模式各自记住自己的选择）
4. 改完立即生效；若在任务中修改，下一局生效
