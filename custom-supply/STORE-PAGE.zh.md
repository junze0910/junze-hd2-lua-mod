# 自定义补给（Custom Supply）

**项目地址 / 下载：** https://github.com/junze0910/junze-hd2-lua-mod/releases/latest
**当前版本：** v0.1f

## Description · 简介

把补给包架的 **4 个槽位**变成可配置：**放什么，决定补给给什么；放多少，决定冷却多久。**

- 上层每槽 7 选 1：`无 / 弹药盒 / 针剂盒 / 手雷盒 / 补给包 / 医疗包 / 爆炸筒`
- v0.1f 改版：MODS 页只剩 **5 行** —— 1 行「**模式**」（补给 / 大炮覆盖）+ 4 行「**槽位**」；切到大炮模式后这 4 行的下拉**直接换成 SEAF 炮弹**（补给类则回退上层同槽补给），两个模式各自记住自己的选择
- 冷却按实际生效内容自动计算：**30 s（四槽全无 / 爆炸筒）～ 150 s（四槽针剂盒 / 补给包 / 迷你核弹）**
- 全部改动发生在**运行时内存**，不修改任何游戏文件；禁用 mod 后重启游戏即完全还原

## Main features · 主要特性

### 1. 四个槽位独立配置

在游戏原生 **ESC → MODS 页 → 分组 `A HD2 MOD COLLECTION`** 下：`[补给] 模式` + `[补给] 槽位 1 ~ 4`。

### 2. 内容决定冷却

| 槽位里放的 | 简称 | 单件冷却增量 |
|---|---|---:|
| （空槽） | 无 | +0 s |
| 资源点弹药盒 | 弹药盒 | **+5 s** |
| 资源点治疗针剂 | 针剂盒 | **+30 s** |
| 资源点手榴弹包 | 手雷盒 | **+15 s** |
| 补给（模型） | 补给包 | **+30 s** |
| 医疗补给（模型） | 医疗包 | **+15 s** |
| 爆炸筒（Explosive Barrel） | 爆炸筒 | **+0 s** |

```
冷却 = 30 + 5×弹药盒 + 30×针剂盒 + 15×手雷盒 + 30×补给包 + 15×医疗包
        + 0×爆炸筒
```

| 举例 | 冷却 |
|---|---:|
| 无 / 无 / 无 / 无 ← **默认** | **30 s** |
| 弹药盒 ×4 | 50 s |
| 手雷盒 ×4 或 医疗包 ×4 | 90 s |
| 弹药盒 + 针剂盒 + 手雷盒 + 医疗包 | 95 s |
| 针剂盒 ×4 或 补给包 ×4 | **150 s（上限）** |
| 爆炸筒 ×4（或四槽全无） | 30 s |

### 3. 摆位自动套用

针剂盒与手雷盒放在包架上时，mod 会自动套用调好的位置与朝向：

| 物品 | 偏移 (X,Y,Z) | 旋转 (X,Y,Z) |
|---|---|---|
| 针剂盒 | `(0, -0.1, -0.1)` | `(-90, 0, 0)` |
| 手雷盒 | `(0.1, -0.3, 0)` | `(-90, 0, 0)` |
| 爆炸筒 | `(0, 0, 0)` | `(0, 0, 0)` |

爆炸筒与其余物品写 0，不改变外观。

### 2.5 大炮覆盖模式（v0.1f 起）

**模式**切到「大炮覆盖」后，同样那 4 行的下拉内容直接换成炮弹（不需要时切回「补给」即可）。

- **关闭**（默认）：只读上层 4 个补给槽，下层 4 槽忽略。
- **打开**：新增的 4 个「大炮槽位」逐槽生效：
  - 选「**补给类**」→ 沿用上面对应补给槽的物品；
  - 选炮弹 / 爆炸筒 → 用下层选中的物品。
- 上下两层**独立配置**，不互相同步。

| 下层可选 | CD 增量 |
|---|---:|
| 补给类 | 取上层 |
| 大炮 迷你核弹 | +30 s |
| 大炮 高爆弹 | +20 s |
| 大炮 炸弹 | +15 s |
| 大炮 凝固汽油弹 | +10 s |
| 大炮 静电场 | +10 s |
| 大炮 烟雾弹 | +5 s |
| 爆炸筒 | +0 s |

炮弹摆位统一 `(0,0,0)/(0,0,0)`。

### 4. 自带"让补给可用"

不需要再装解锁类 mod：本 mod 会自己完成让这台补给战备可用所需的处理。

### 5. 每 5 秒复核

自动复核 **选择位 / 可用状态 / 冷却 / 4 个槽位**，被游戏改回会立刻补回。

### 6. 会话级、可还原

写入只在本次游戏进程内有效；重启游戏即回到原装。想立刻还原：把 4 个槽位都选「无」并进一次任务，或禁用 mod 后重启。

## Operation flow · 操作流程

1. **装前置**：Bingus Shared Loader（v15+ / API 1）+ **HD2 Scanner v0.8.1+**（本 mod 靠它定位战备表与包架表，并读统一的 MODS 分组名）
2. **装本 mod**：`Custom-Supply-v0.1f.zip`
3. **进一次任务**（战备表/包架表只在进任务后加载）
4. **配置**：ESC → MODS → `A HD2 MOD COLLECTION` → `[补给] 槽位 1~4`（下拉描述里会**实时显示当前冷却**）；若场上存在超级地球大炮，把 `[补给] 模式` 切到「大炮覆盖」，同样那 4 行的下拉就变成炮弹
5. **生效**：改完立刻生效；若在任务中修改，下一局生效（战备列表在进任务时构建）

## Compatibility · 兼容性

- 只改**补给战备（ID77 `CONSUMABLES. HEALTH PACK RACK`）所用的那台包架**的 4 个激活槽，不碰其它表
- 运行时内存写入，不改磁盘文件；与其它 mod 共存
- 不新增槽位、不改槽位数量

## Known limits · 已知限制

- 未做"一键还原"按钮；没有"预设组合"（四槽独立选）
- **v0.1d 的「爆炸筒」与 v0.1e 的「SEAF 大炮覆盖」均已实机通过**（用户确认，2026-10-04）
- 队友那一侧显示成什么**未验证**（取决于他们自己的游戏数据）
- 游戏版本变化可能导致定位失败 —— 此时 mod 会**拒写并记日志**，不会乱写
