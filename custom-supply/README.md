## 1. 装什么 → CD 多久

| 简称 | 官方名 | 单件 CD 增量 |
|---|---|---:|
| 无 | （空槽） | +0 s |
| **弹药盒** | 资源点弹药盒 | **+5 s** |
| **针剂盒** | 资源点治疗针剂 | **+30 s** |
| **手雷盒** | 资源点手榴弹包 | **+15 s** |
| **补给包** | 补给（模型） | **+30 s** |
| **医疗包** | 医疗补给（模型） | **+15 s** |
| **爆炸筒** | 爆炸筒（Explosive Barrel） | **+0 s** |

```
CD = 30 + 5×弹药盒 + 30×针剂盒 + 15×手雷盒 + 30×补给包 + 15×医疗包
       + 0×爆炸筒
```

| 填装 | CD |
|---|---:|
| 无 / 无 / 无 / 无 ← **默认** | **30 s** |
| 弹药盒 ×4 | 50 s |
| 手雷盒 ×4 / 医疗包 ×4 | 90 s |
| 弹药盒 + 针剂盒 + 手雷盒 + 医疗包 | 95 s |
| 针剂盒 ×2 + 手雷盒 ×2 | 120 s |
| 针剂盒 ×4 / 补给包 ×4 | **150 s（上限）** |
| 爆炸筒 ×4（或全「无」） | 30 s |

**摆位**：针剂盒与手雷盒会自动套用固定摆位，爆炸筒与其余物品写 0。

| 物品 | 偏移 (X,Y,Z) | 旋转 (X,Y,Z) |
|---|---|---|
| 针剂盒 | `(0, -0.1, -0.1)` | `(-90, 0, 0)` |
| 手雷盒 | `(0.1, -0.3, 0)` | `(-90, 0, 0)` |
| 爆炸筒 | `(0, 0, 0)` | `(0, 0, 0)` |

### 大炮覆盖模式（v0.1f 起）

MODS 页只有 **5 行**：1 行「**模式**」+ 4 行「**槽位**」。两条模式**共用这 4 行**，下拉内容直接换：

- **模式 = 补给**（默认）：4 行就是上表的补给内容（7 项）。
- **模式 = 大炮覆盖**：4 行变成 `补给类 / 大炮 迷你核弹(+30s) / 大炮 高爆弹(+20s) / 大炮 炸弹(+15s) / 大炮 凝固汽油弹(+10s) / 大炮 静电场(+10s) / 大炮 烟雾弹(+5s) / 爆炸筒(+0s)`。
  - 选「**补给类**」→ 沿用**同一槽**在补给模式里的物品（含 CD 与摆位）；
  - 选炮弹 / 爆炸筒 → 用炮弹本身的物品；炮弹摆位统一 `(0,0,0)/(0,0,0)`。

**只用在你场上有超级地球大炮 / SEAF Artillery 的时候** —— mod 不做自动检测，由你自己切模式。
两个模式**各自记住**自己的 4 个选择，来回切不会丢；切模式时下拉文字会立刻换成新模式的内容
（MOM 每次开菜单都会重算选项文字）。

## 2. 安装

1. 用 HD2 Mod Manager / Arsenal 装上 `Custom-Supply-v0.1f.zip`
2. **同时确保 HD2 Scanner v0.8.1+ 已启用**（本 mod 靠它定位战备表与包架表，并从它读统一的 MODS 分组名）
3. 启动游戏 → **进一次任务**（战备表/包架表只在进任务后加载）

---

## 3. 配置（游戏内 ESC → MODS 页）

所有 HD2 mod 的选项**统一并进同一个分组 `A HD2 MOD COLLECTION`**（MOM 只显示前 8 个分组，中文标题会被整组截掉）。

- 本 mod 占 **5 行**，都带 `[补给]` 前缀：
  - **`[补给] 模式`** —— 补给 / 大炮覆盖
  - **`[补给] 槽位 1 ~ 4`** —— 选项随模式变
- 补给模式每个下拉 7 个选项：`无 / 弹药盒 / 针剂盒 / 手雷盒 / 补给包 / 医疗包 / 爆炸筒`
- 大炮模式每个下拉 8 个选项：`补给类 / 6 种炮弹 / 爆炸筒`
- 每条选项下方的灰字会**实时显示**「当前 CD = xx s（补给/SEAF 覆盖：…）」
- **默认 = 补给模式、四槽全「无」→ 30 s**

## 4. 生效时机

| 时机 | 行为 |
|---|---|
| 每次启动游戏 | 自动重写一次（内存改动是**会话级**，重启即回到原装） |
| 改任意槽位 | 立刻重算并写入 |
| 每 5 秒 | 复核 5 项（选择位 / 可用状态 / 冷却 / 4 个槽位），被游戏改回会**自动补回** |
| 在飞船里配置 | 进任务后生效 |
| 进任务后再改 | 下一局生效（战备列表在进任务时构建） |

本 mod **自带**"让补给战备可用"的处理（不需要额外装解锁类 mod）。

## 5. 排障

日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CustomSupply.log`

| 现象 | 先看什么 |
|---|---|
| MODS 页里没有「A HD2 MOD COLLECTION」分组 | `Logs\MDL-Boot.log` 应有一行 `mods/dsh/custom_supply: loaded`；没有 = 安装/启用问题 |
| 改了槽位但没变化 | `CustomSupply.log` 末尾的 `★` 行。出现 `注册表定位失败：门闸 = 0` 说明表还没就绪 → **进一次任务** |
| 冷却没变 | 同上；确认日志里有 `★ 冷却 id=77 cooldown_success = xx s` |
| 战备列表里找不到这台补给 | 日志应有 `★ 可用状态 id=77 记录#841 1 -> 2（回读通过）`；没有就把日志尾部发给我 |
| 包架内容没变 | 日志应有 `已向 Scanner 请求扫描包架表` → `包架表已定位 0x…` → `★ 槽1..4 = …` |

## 6. 已知限制

- 只作用于**补给包架**（战备 ID77 用的那台，4 个激活槽）；**不新增槽位**
- 未做"还原/复位"按钮；没有"预设组合"（每槽独立选；那是 TD-110 那条线的做法）
- **v0.1b 已实机验证**（2026-10-04，构建号 46015）：上机清单见文首
- **v0.1d 的「爆炸筒」与 v0.1e 的「SEAF 大炮覆盖」均已实机通过**（用户确认，2026-10-04）
- **v0.1f 的 MODS 页改版**（模式 + 4 共用槽位）待实机验证；离线夹具：纯逻辑 36/36 + 合成内存 29/29 + SEAF 覆盖 58/58
- 支持的游戏构建：`helldivers2.exe` 1.8.46015.0（Steam build 25480438）；换版本可能失效（mod 会拒写并记日志）
- 改的是**本地内存**：只保证自己这台机器上的效果；队友那一侧显示成什么**未验证**（取决于他们自己的游戏数据）
