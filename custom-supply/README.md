**版本：v0.1e（已实机通过，已发布）** ｜ 前置：**Bingus Shared Loader** + **HD2 Scanner v0.8.0+**

> ✅ **v0.1b 实机验证通过（2026-10-04）**：解锁（选择位 + 可用状态）、包架 4 槽写入（含摆位规范值）、CD 写入（实测 45/75/90/95/120 s 与公式逐项吻合）、改槽即时生效、门闸未就绪时自动重试 —— 全部在游戏内确认。

> 一句话：**往补给包架的 4 个槽位里放什么，决定投下来的补给给什么、以及补给战备冷却多久。**

## 1. 装什么 → CD 多久

| 简称 | 官方名 | 单件 CD 增量 |
|---|---|---:|
| 无 | （空槽） | +0 s |
| **弹药盒** | 资源点弹药盒 | **+5 s** |
| **针剂盒** | 资源点治疗针剂 | **+30 s** |
| **手雷盒** | 资源点手榴弹包 | **+15 s** |
| **补给包** | 补给（模型） | **+30 s** |
| **医疗包** | 医疗补给（模型） | **+15 s** |
| **爆炸筒** | 爆炸筒（Explosive Barrel） | **+0 s** |

```
CD = 30 + 5×弹药盒 + 30×针剂盒 + 15×手雷盒 + 30×补给包 + 15×医疗包
       + 0×爆炸筒
```

| 填装 | CD |
|---|---:|
| 无 / 无 / 无 / 无 ← **默认** | **30 s** |
| 弹药盒 ×4 | 50 s |
| 手雷盒 ×4 / 医疗包 ×4 | 90 s |
| 弹药盒 + 针剂盒 + 手雷盒 + 医疗包 | 95 s |
| 针剂盒 ×2 + 手雷盒 ×2 | 120 s |
| 针剂盒 ×4 / 补给包 ×4 | **150 s（上限）** |
| 爆炸筒 ×4（或全「无」） | 30 s |

**摆位**：针剂盒与手雷盒会自动套用固定摆位，爆炸筒与其余物品写 0。

| 物品 | 偏移 (X,Y,Z) | 旋转 (X,Y,Z) |
|---|---|---|
| 针剂盒 | `(0, -0.1, -0.1)` | `(-90, 0, 0)` |
| 手雷盒 | `(0.1, -0.3, 0)` | `(-90, 0, 0)` |
| 爆炸筒 | `(0, 0, 0)` | `(0, 0, 0)` |

### SEAF 大炮覆盖（v0.1e）

- 新开关「**SEAF 大炮覆盖**」：**仅当场上存在超级地球大炮 / SEAF Artillery 时，由玩家自己手动打开**；mod 不做自动检测。
- **关闭**（默认）：只读上面 4 个补给槽，下层 4 槽被忽略。
- **打开**：新增的 4 个「大炮槽位」逐槽生效：
  - 下层选「**补给类**」→ 沿用上面对应补给槽的物品（含 CD 与摆位）；
  - 下层选炮弹 / 爆炸筒 → 用下层选中的物品。
- 上下两层**独立配置**，不互相同步；下层默认全「补给类」。
- 下层可选：`补给类 / 大炮 迷你核弹(+30s) / 大炮 高爆弹(+20s) / 大炮 炸弹(+15s) / 大炮 凝固汽油弹(+10s) / 大炮 静电场(+10s) / 大炮 烟雾弹(+5s) / 爆炸筒(+0s)`；炮弹摆位统一 `(0,0,0)/(0,0,0)`。

## 2. 安装

1. 用 HD2 Mod Manager / Arsenal 装上 `Custom-Supply-v0.1e.zip`
2. **同时确保 HD2 Scanner v0.8.0+ 已启用**（本 mod 靠它定位战备表与包架表）
3. 启动游戏 → **进一次任务**（战备表/包架表只在进任务后加载）

---

## 3. 配置（游戏内 ESC → MODS 页）

- 分组「**自定义补给**」下：
  - **补给槽位 1 ~ 4**（上层，各自独立）
  - **SEAF 大炮覆盖**（开关，默认关；仅当存在超级地球大炮时手动打开）
  - **大炮槽位 1 ~ 4**（下层，各自独立；选项 = 补给类 / 6 种炮弹 / 爆炸筒）
- 上层每个下拉 7 个选项：`无 / 弹药盒 / 针剂盒 / 手雷盒 / 补给包 / 医疗包 / 爆炸筒`
- 每条选项下方的灰字会**实时显示**「当前 CD = xx s（补给/SEAF 覆盖：…）」
- **默认 = 开关关、上层四槽全「无」→ 30 s**

---

## 4. 生效时机

| 时机 | 行为 |
|---|---|
| 每次启动游戏 | 自动重写一次（内存改动是**会话级**，重启即回到原装） |
| 改任意槽位 | 立刻重算并写入 |
| 每 5 秒 | 复核 5 项（选择位 / 可用状态 / 冷却 / 4 个槽位），被游戏改回会**自动补回** |
| 在飞船里配置 | 进任务后生效 |
| 进任务后再改 | 下一局生效（战备列表在进任务时构建） |

本 mod **自带**"让补给战备可用"的处理（不需要额外装解锁类 mod）。

## 5. 排障

日志：`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CustomSupply.log`

| 现象 | 先看什么 |
|---|---|
| MODS 页里没有「自定义补给」 | `Logs\MDL-Boot.log` 应有一行 `mods/dsh/custom_supply: loaded`；没有 = 安装/启用问题 |
| 改了槽位但没变化 | `CustomSupply.log` 末尾的 `★` 行。出现 `注册表定位失败：门闸 = 0` 说明表还没就绪 → **进一次任务** |
| 冷却没变 | 同上；确认日志里有 `★ 冷却 id=77 cooldown_success = xx s` |
| 战备列表里找不到这台补给 | 日志应有 `★ 可用状态 id=77 记录#841 1 -> 2（回读通过）`；没有就把日志尾部发给我 |
| 包架内容没变 | 日志应有 `已向 Scanner 请求扫描包架表` → `包架表已定位 0x…` → `★ 槽1..4 = …` |

## 6. 已知限制

- 只作用于**补给包架**（战备 ID77 用的那台，4 个激活槽）；**不新增槽位**
- 未做"还原/复位"按钮；没有"预设组合"（每槽独立选）
- **v0.1b 已实机验证**（2026-10-04，构建号 46015）：上机清单见文首
- **v0.1d 的「爆炸筒」与 v0.1e 的「SEAF 大炮覆盖」均已实机通过**（用户确认，2026-10-04）
- 离线夹具：纯逻辑 36/36 + 合成内存 29/29 + SEAF 覆盖 49/49
- 支持的游戏构建：`helldivers2.exe` 1.8.46015.0（Steam build 25480438）；换版本可能失效（mod 会拒写并记日志）
- 改的是**本地内存**：只保证自己这台机器上的效果；队友那一侧显示成什么**未验证**（取决于他们自己的游戏数据）
